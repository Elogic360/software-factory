# Repository Intelligence & Scoring Rubric

## Quality Scoring Equation
```
CapabilityScore = (
  Maintenance * 0.15 +
  Security * 0.15 +
  License * 0.10 +
  Test Quality * 0.10 +
  Documentation * 0.10 +
  Integration Value * 0.15 +
  Agent Usefulness * 0.15 +
  Performance * 0.05 +
  Community * 0.05
) - Deductions
```

## Score Classification
- **Grade A (90–100)**: Immediate Core Adoption.
- **Grade B (80–89)**: Specialized / Domain Pack Adoption.
- **Grade C (70–79)**: Experimental / Quarantined Sandbox.
- **Grade D (60–69)**: Reference Documentation Only.
- **Grade REJECTED (<60)**: Excluded from Factory.
