## 🛠️ How to Provision Any Tool in a New Project

When spinning up a new project or adding capabilities to an existing repository:

```bash
# 1. Run the software-factory installer
cd /path/to/any-project
bash /home/elogic360/Desktop/little\ QUANTUM/IntegralMarket/software-factory/install.sh

# 2. Select and load relevant skills
python3 software-factory/context-engine/skill_selector.py --query "<your feature or task>"

# 3. Consult TOOLBOX.md for libraries, packages, or MCP servers needed
cat software-factory/TOOLBOX.md | grep -A 5 "<domain>"
```
