# Spec-Driven Development Pipeline

Lifecycle
1. IDEA: capture intent and outcomes
2. SPEC: define user scenarios, requirements, success criteria
3. PLAN: architecture, data model, contracts, quickstart
4. TASKS: dependency-ordered tasks with validation
5. IMPLEMENT: incremental delivery by user story
6. VALIDATE: tests, checks, and functional verification
7. REFINE: documentation and cleanup

Quality Gates
- Constitution check before planning
- Task validation before implementation
- Validation report before merge

Artifacts
- specs/<feature>/spec.md
- specs/<feature>/plan.md
- specs/<feature>/tasks.md
- Optional: research.md, data-model.md, contracts/
