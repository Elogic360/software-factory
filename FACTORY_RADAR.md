# Factory Radar — Continuous Ecosystem Discovery

## Purpose
Factory Radar proactively surveys GitHub, NPM, PyPI, and agent marketplaces to identify breakthrough tools, libraries, and MCP servers.

## Scan Frequency & Categories
- **Daily**: Agent harnesses, coding CLI tools, security CVEs.
- **Weekly**: Domain libraries (Quant, ML, Web), MCP servers.
- **Monthly**: Academic research, benchmark datasets.

## CLI Invocation
```bash
python3 factory.py radar --period daily
python3 factory.py radar --category quant
```
