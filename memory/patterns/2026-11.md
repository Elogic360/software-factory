# Architectural Patterns & Factory Memory — November 2026

## 1. Microservice Boundary & Local Runtime Topology
- **Market Core API (`:8000`):** Authentication, Users, Academy, Library, Products, Tunzaa Payments, R2 Proxy.
- **Expert Execution API (`:8002`):** IMCharts, IMExpert, MT5 Node Registry, cTrader Execution, Journal Aggregation.
- **Market Intelligence (`:8003`):** Technical indicators, macro sentiment, order flow metrics.
- **Sensei AI Copilot (`:8010`):** Vector memory RAG, tutor agents, tool calling.
- **Transactional Mail (`:8011`):** Stalwart/Bulwark mail delivery and template management.
- **MT5 Worker Gateway (`:9100`):** Rootless Podman container `mt5-worker-node1`.
- **Frontend SPA Preview (`:5173`):** Vite production preview with environment-aware API proxying.

## 2. Multi-Broker Visual & Technical Normalization
- All supported broker platforms implement standard capability interfaces:
  - Account Authentication (Credentials vs OAuth2).
  - Symbol Resolution & Order Specification.
  - Position Monitoring & Stream Sockets.
  - Historical Trade Import to Journal.
- UI layer uses single-source brand configs (`broker-brands.config.ts`) with vector SVGs and authentic platform badges.

## 3. Financial Metrics & Chart Rendering Invariants
- Numbers representing PnL, Win Rate, Drawdown, Profit Factor, Sharpe Ratio, and R:R must display at least 2 decimal places.
- Font styling must apply `.tabular-nums` and `.font-mono` to prevent layout shift during realtime ticks.
- Dual-axis charts must fallback to trade-by-trade progression when date grouping yields fewer than 2 points.

## 4. Cloudflare R2 Streaming & Resilient Fallback Pattern
- Object keys can omit or include bucket prefixes (`academy/`, `library/`, `covers/`).
- The proxy endpoint iterates candidate buckets in priority order.
- Differentiated SVG fallbacks ensure document readers receive book iconography and video viewers receive playback timeline iconography.
