# AI/ML & LLM Engineering Domain Pack

Provides end-to-end tooling, evaluation harnesses, RAG retrievers, and prompt engineering frameworks.

## 🧰 Integrated Libraries
- **Transformers** (`huggingface/transformers`): SOTA text, vision, and audio models.
- **LlamaIndex** (`run-llama/llama_index`): Document parsing, OCR, and vector index retrieval.
- **LangChain** (`langchain-ai/langchain`): Agent orchestration and tool routing.
- **Ragas** (`vibrantlabsai/ragas`): Automated evaluation of RAG faithfulness and precision.
- **DocETL** (`ucbepic/docetl`): Complex agentic data transformations and summarization.
