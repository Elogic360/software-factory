# Roles and Ownership

This file maps roles to skills under .claude/skills/roles.

Core Roles
- Architect Principal: architecture, boundaries, contracts
- Software Developer: feature delivery and refactoring
- Frontend Engineer: React UI and client performance
- UI/UX Designer: design system and interaction
- Backend Engineer: FastAPI services and APIs
- Database Engineer: schema, migrations, performance
- DevOps Engineer: CI/CD, infra, monitoring
- SEO Engineer: discoverability and metadata
- AI Optimization Engineer: prompt/agent performance
- Context Engineer: context compression and retrieval
- Prompt Engineer: master prompts and system guidelines
- QA Engineer: test strategy and validation
- Security Engineer: threat modeling and access control
- Observability Engineer: metrics, logs, traces
- Performance Engineer: profiling and scalability

Each role is implemented as a skill package in .claude/skills/roles.
