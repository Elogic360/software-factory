# 🔌 Software Factory Model Context Protocol (MCP) System

## Canonical Factory MCP Servers (`custom-mcp/`)
1. **factory-context-mcp** (`custom-mcp/factory_context_server.py`): Exposes context ranking, compression, deduplication, and token budgeting.
2. **factory-memory-mcp** (`custom-mcp/factory_memory_server.py`): Exposes 28-neuron memory search, retrieval, recall, and product genealogy.
3. **factory-architecture-mcp** (`custom-mcp/factory_architecture_mcp.py`): Exposes C4 modeling, Mermaid rendering, and drift analysis.
4. **factory-sdd-mcp** (`custom-mcp/factory_sdd_mcp.py`): Exposes spec-to-plan compilation, work orders, and quality gate evaluations.
