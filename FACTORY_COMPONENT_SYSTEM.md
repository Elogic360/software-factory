# 🧩 Reusable Component & Raw Materials System

## Raw Materials Warehouse (`warehouse/raw-materials/`)
Production-ready modules ready for assembly:
- `fastapi-enterprise-scaffold`: Async API routes, lifespan handlers, Pydantic schemas.
- `auth-foundation`: OAuth2, JWT verification, RBAC, password hashing.
- `realtime-websockets`: Connection manager, heartbeat, pub/sub broadcaster.
- `trading-risk-engine`: Pre-trade checks, margin validation, drawdowns.
- `rag-vector-retrieval`: Qdrant vector indexing and chunking.
